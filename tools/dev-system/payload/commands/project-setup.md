---

현재 프로젝트를 개발부서 체계(`/dev`)에서 쓸 수 있게 준비한다.

1. `~/.claude/dev-system/claudemd-spec.md`를 읽는다.
2. 그 문서의 **필수 항목 7개**와 **준비 상태 판정**(충분/부족/없음) 기준으로 현재 프로젝트의 `CLAUDE.md`를 점검한다.
3. **작성 절차**대로 진행한다: 코드와 설정 파일을 읽어 확인된 것만 채우고, 확인 못 한 항목은 `(확인 필요)`로 두었다가 사용자에게 한 번에 묻는다.
4. 초안(또는 보강안)을 보여 주고 **승인받은 뒤에만** `CLAUDE.md`를 쓴다. 기존 내용은 덮어쓰지 않는다. 시크릿 값은 적지 않는다.
5. 끝나면 항목별 상태 표(충분/보강함/확인 필요)와, 남은 `(확인 필요)` 목록을 보고한다.

이 명령은 코드 수정·커밋·푸시를 하지 않는다(CLAUDE.md 작성만, 승인 후).
